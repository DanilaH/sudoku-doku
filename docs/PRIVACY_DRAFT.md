# Политика конфиденциальности — проект для заполнения владельцем

Приложение «Судоку». Владелец/оператор: Хитев Данила Сергеевич. Контакт для обращений: hityov.danila@yandex.ru. Дата вступления в силу: [указать]. Это проект, не готовая опубликованная политика.

Партия, заметки, история действий, настройки и статистика сохраняются локально на устройстве. Приложение не требует аккаунта. Локальные данные можно удалить средствами операционной системы; удаление приложения может удалить прогресс.

В Android-сборке используется Yandex Mobile Ads для показа рекламы. При наличии ключа приложения используется AppMetrica для технической диагностики и анализа работы игры. SDK могут обрабатывать рекламный идентификатор, параметры устройства, версию ОС/приложения, сетевые сведения, события рекламы, ошибки и события использования приложения. Геолокация и контакты не запрашиваются приложением. Ручной сбор рекламных интересов отсутствует.

Продуктовые события включают начало/продолжение/завершение партии, сложность, активное время, число подсказок и коды ошибок. Не передаётся каждый ход или полная история заметок. Идентификатор партии служит для устранения дублей событий.

Обычная веб-сборка не подключает рекламные/аналитические SDK. В Яндекс Играх действуют SDK и правила обработки данных этой платформы. Информация о правилах Яндекса: https://yandex.ru/legal/confidential/.

Перед публикацией владелец должен дополнить сведения об основаниях обработки, сроках хранения у подключённых сервисов, правах пользователя и применимых требованиях. Фактическую сборку и декларации магазина требуется сверить с этой политикой.
