# Интерфейс 0.3 — 15 октября 2026

## Решение пользователя
Первая версия интерфейса отвергнута как шаблонная: бежевый/зелёный, слоганы, декоративные элементы. Из двух макетов понравилась компоновка A, но предложенные палитры не приняты. Пользователь попросил использовать уже собранные скриншоты, затем разрешил переделать весь интерфейс.

Основной визуальный референс: последняя пачка скриншотов, Brainatee Sudoku, экран игры 131847, панель оформления 131631 и диалог 131931. Это ориентир для пропорций и визуальной логики; чужие изображения и ассеты в приложение не включаются.

## Визуальная система
- Почти белые нейтральные поверхности #f7f8fc/#ffffff, тёмный текст #23272c.
- Основные цифровые кнопки #365f8b, белые цифры; без общего голубого тонирования всех поверхностей.
- Тёмные границы блоков 3×3, тонкие внутренние линии, обычное начертание цифр. Ввод выделяется цветом, исходные значения остаются нейтральными.
- Связанные области — серые, одинаковые цифры — голубовато-серые, выбранная клетка — голубая с обводкой. Ошибка дополнительно подчёркнута.
- Тёмная тема — наша адаптация той же иерархии; референс тёмной темы в предоставленной пачке отсутствует.
- Крупные цифры увеличивают только значения; заметки остаются сеткой 3×3.

## Экраны и управление
- Главная: продолжение с реальным заполнением и временем, новая игра, задача дня, вспомогательная навигация. Без лозунгов и декоративного поля.
- Партия: назад, название, пауза, настройки; сложность и время непосредственно над полем. Четыре инструмента: отмена, стирание, заметки с Вкл/Выкл, подсказка.
- На узких телефонах цифровые кнопки в два ряда. Один ряд включается только при достаточной ширине; кнопки не меньше 48×48 CSS px.
- Режим ввода в компактном раскрывающемся меню. Повтор хода и проверка доступны под клавиатурой. Горячие клавиши сохранены.
- Успешное сохранение больше не занимает визуальную панель и не объявляется на каждом ходе. Ошибки сохранения остаются видимыми.
- Настройки сгруппированы: тема, экран, подсветка, управление. Календарь, статистика, обучение, подсказки, проверка, пауза и победа используют общую систему.
- Цвет браузерной панели следует теме. Название и Android splash/icon приведены к новому оформлению.

## Проверки
Существующие сценарии игры, сохранений, пауз, ежедневных задач и Yandex SDK сохраняются. Дополнительный сценарий проходит экраны и проверяет крупные цифры/заметки, тёмную тему, меню ввода, размеры кнопок, отсутствие горизонтального переполнения и доступность управления на 360×640, 390×844, 520×900 и 1280×800. Скриншоты — реальные рендеры приложения. При увеличенном системном масштабе допускается прокрутка.

Исправлена найденная в процессе проверки рассинхронизация отображения таймера: при нажатии паузы окончательное активное время отображается сразу, а не при следующем 500-миллисекундном обновлении.

Не меняются правила судоку, банк, схема сохранения и рекламные ограничения. Новые магазины, награды, ранги и другие системы не добавляются.
